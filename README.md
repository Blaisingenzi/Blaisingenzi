### 🚀 Featured project: IngenziDoctors

> **Find what is wrong with your PC, in plain language.**

IngenziDoctors scans a PC from the hardware up to crash dumps and event logs, then combines the evidence into clear findings with steps to fix them. Scan results never leave the PC.

| Part | Built with |
|---|---|
| 🖥️ Desktop app | Python 3.12, PySide6, Qt Quick (QML), psutil, ONNX Runtime |
| ⚙️ Backend API | FastAPI, SQLAlchemy 2, Alembic, PostgreSQL, JWT, argon2 |
| 🌐 Website | React 18, TypeScript, Vite, Tailwind CSS, Framer Motion |
| 🧠 Photo model | PyTorch (MobileNetV3), exported to ONNX |
| 📦 Delivery | PyInstaller, Inno Setup, Docker, GitHub Actions CI |

64+ automated tests cover auth, sessions, crash-dump parsing, rules, exports and i18n.
